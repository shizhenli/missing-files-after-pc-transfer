symptoms:
- title: A folder looks emptier
  text: The new PC has the folder name, but documents, photos, or project files are missing from it.
- title: Dates and versions conflict
  text: The same filename exists on both PCs with different modified dates, and it is unclear which one is current.
- title: Files will not open
  text: The copy completes, but a sample file is corrupt, locked, or missing its associated application data.
checks:
- title: Agree the exact folder list
  text: Write down the source and destination paths before copying. “My Documents” or a desktop shortcut is not a reliable scope.
- title: Compare names, counts, and dates
  text: Use a folder comparison tool or exported file list. Record missing paths and same-name/different-date conflicts separately.
- title: Copy to a staging folder
  text: Copy missing items into a new staging folder first. Do not overwrite the only good copy on the old PC.
- title: Open a sample from the new PC
  text: Open several files of each type from their final location and confirm the application data and permissions.
included:
- One old and one new Windows PC

- Missing-file copy and conflict list
- Sample open and readability checks
excluded:
- Data recovery from failed drives
- Account or license migration
- Guaranteed recovery of overwritten files
- Application-specific database repair
faqs:
- q: Can you find every missing file?
  a: We can reconcile the folders you name and report what is absent. Files never copied, overwritten, or stored elsewhere need a separate recovery path.
- q: Will you overwrite the new PC?
  a: No. Missing items go to a staging folder first; same-name conflicts are reviewed before anything replaces an existing file.
- q: Do you need my Windows password?
  a: No. Use a local temporary account or stay present for the session. We never ask for your Microsoft account password.
