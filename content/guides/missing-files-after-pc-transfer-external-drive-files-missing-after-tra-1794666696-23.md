You copied your user folders to an external drive, but after transferring to the new PC, the folders or files are missing—this guide helps you diagnose and fix that incomplete copy.

## Check the External Drive Directly

First, reconnect the external drive to the old PC. Open File Explorer and navigate to the drive. Look for your user folders (Desktop, Documents, Downloads, Pictures). If they are absent or empty, the first copy did not complete. Check the drive's free space and compare it to the size of your user folders. If free space is much larger than expected, the copy likely stopped early.

## Inspect for Hidden or System Files

On the new PC, enable hidden items in File Explorer's View tab. Sometimes folders are marked hidden during transfer. Also check the external drive for a folder named "Windows.old" or similar—this can indicate a backup was created instead of a direct copy.

## Run a Verification Test

Create a small test folder on the old PC with a few files. Copy it to the external drive, then to the new PC. If the test folder appears correctly, the issue is specific to the original copy. If it also fails, the drive or connection may be faulty.

## Restore Missing Files

If the copy was incomplete, recopy the user folders using a reliable method: select the folders, right-click, and choose Send to > External Drive. Avoid dragging if the folders are large. After copying, safely eject the drive and reconnect to the new PC. Verify each folder's contents. If files are still missing, the **external drive files missing after transfer** may require deeper recovery—consider using file recovery software or checking for bad sectors.
