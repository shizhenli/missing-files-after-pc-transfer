## Troubleshooting

You finished copying your user folders to an external drive, but now the drive appears empty on the new PC. First, confirm you are looking at the correct drive letter. Open File Explorer, right-click the external drive, and choose Properties. If the Used space shows several gigabytes but the folder list is blank, the files exist but are hidden or the copy was interrupted. Check for hidden items: on the View tab, enable Hidden items. If your user folders appear, the transfer completed but attributes were changed. Next, verify the source path. On the old PC, open the external drive and navigate to the folder you copied. If the folder is empty there, the first copy never finished. Look for a folder named after your old PC or user profile; Windows sometimes nests copies inside an extra directory. If you find your files there, move them to the drive root. Run a verification test: create a small text file on the external drive, eject it safely, reconnect it, and confirm the file is visible. If it disappears, the drive may have a failing connection or file system error. For recovery, do not write new data to the drive. Use Windows File History or a backup to restore missing items, and recopy user folders one at a time, checking after each.
