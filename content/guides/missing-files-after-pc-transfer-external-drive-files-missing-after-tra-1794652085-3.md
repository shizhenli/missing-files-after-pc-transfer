## Troubleshooting

You copied your user folders to an external drive, but now the drive shows empty or incomplete folders on the new PC. ## Check the drive and folder view First, reconnect the external drive and open File Explorer. In the View tab, enable Hidden items and File name extensions. Then navigate to the drive root and look for your user folder (e.g., Users\YourName). If the folder exists but appears empty, right-click it, choose Properties, and compare the size and file count with what you expected. A zero-byte folder suggests the copy was interrupted or pointed to the wrong path. ## Verify the copy source and destination Open the original PC (or its backup) and confirm the files still exist there. On the new PC, check whether you copied into a subfolder by mistake—search the drive for a known file name using the search box. If the search finds nothing, the transfer likely failed silently. ## Run a verification test Create a small test folder on the external drive, copy one document into it, eject safely, reconnect, and confirm the file is present. If the test file disappears, the drive or cable is suspect. ## Rollback and recovery If files are still absent, do not write new data to the drive. Use Windows File History or a backup to restore the missing user folders. For a failed copy, recopy from the source using a direct connection (no hub) and verify each folder’s size.
