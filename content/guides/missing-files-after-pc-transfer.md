**files missing after pc transfer**. 

<p>A new PC can look complete while whole subfolders are absent or same-name files have different dates. Compare before copying so you do not overwrite the only good version.</p>
<h2>Before you start</h2><ul>
<li>Access to both Windows PCs</li>
<li>The exact source and destination folder paths</li>
<li>Enough free space for a staging copy</li>
<li>Permission to read the files on both machines</li>
</ul>
<h2>Step-by-step checks</h2>
<h3>Step 1: Write the scope</h3>
<p>List the top-level folders that matter: documents, photos, projects, and application data. Record each source and destination path; leave system folders and program files out of the file migration.</p>
<p>Check: Both sides have a written path list and an owner for each folder.</p>
<h3>Step 2: Export a comparable file list</h3>
<p>Use a folder comparison utility or PowerShell to export relative path, size, and modified date for both sides. Normalize the root path so names can be compared.</p>
<p>Check: The two lists can be matched by relative path without manual guessing.</p>
<h3>Step 3: Classify the differences</h3>
<p>Mark each item missing, newer on one side, same name/different date, or unreadable. Do not treat every difference as a copy failure; some files are intentionally local.</p>
<p>Check: Every discrepancy has one status and a decision.</p>
<h3>Step 4: Stage the missing copy</h3>
<p>Copy only the missing or approved files into a new staging folder on the new PC. Preserve folder structure and do not merge into the live destination yet.</p>
<p>Check: The staged count matches the approved copy list.</p>
<h3>Step 5: Promote and open samples</h3>
<p>Move the staged files into place, then open several files of each type from their final path. Confirm dates, permissions, and application links.</p>
<p>Check: A sample from every file type opens from the new PC.</p>
<h2>Verify the result</h2>
<p>Re-run the comparison after the copy. Missing items should be zero for the agreed scope; remaining conflicts should be explicitly accepted.</p>
<h2>Rollback</h2>
<p>Keep the old PC and the staging folder unchanged until the new copy passes. If a file is wrong, restore from the old PC rather than editing the only copy.</p>
